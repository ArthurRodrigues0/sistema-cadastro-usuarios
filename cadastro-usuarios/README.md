# 🧑‍💻 Sistema de Cadastro de Usuários

Projeto desenvolvido utilizando **Python (Flask)** e **MySQL**, com o objetivo de implementar um sistema CRUD completo (Create, Read, Update, Delete).

---

## 🚀 Funcionalidades

- ✅ Cadastro de usuários
- ✅ Listagem de usuários
- ✅ Edição de dados
- ✅ Exclusão de usuários

---

## 🛠️ Tecnologias utilizadas

- Python
- Flask
- MySQL
- HTML
- CSS

---

## 📷 Interface

Interface simples e funcional para gerenciamento de usuários, com layout centralizado e estilizado.
